# ESEKONE — Public Website

The public product website for ESEKONE, the one stop for your business.

## Local development
```bash
npm install
npm run dev
npm run typecheck
npm run build
```

## Conversion and product positioning
The site introduces ESEKONE as a business operating system connecting customers, projects, sales, commerce, automation, analytics and AI-assisted operations. It is intentionally distinct from the signed-in workspace experience.

The current early-access CTA opens an email draft. Replace it with the production onboarding/signup flow once identity, workspace provisioning, plan selection and consent flows are implemented. No lead or payment data is currently submitted to an API.

## Localization
English and Hebrew content are included with an RTL layout switch. Before launch, complete translation-key coverage, browser locale detection, user locale persistence and accessibility QA for both directions.
